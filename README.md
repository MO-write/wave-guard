# 怪潮守卫 · Wave Guard

> 拖动走位，自动开火，守住中心水晶，看你能扛过多少波怪潮。

单文件、纯 Canvas、零外部素材的竖屏「波次守城」小游戏。双击 `index.html` 即玩，不需要联网、构建或服务器。

- 在线试玩：https://4mdqufrebrmf9.doubao.link/app/app_17jpzbcgn8f
- 引擎：原生 Canvas 2D + WebAudio，设计分辨率 750×1333（9:16），任意屏幕等比缩放
- 包体：单文件约 103 KB，无任何外部图片 / 音频 / 字体

## 玩法

1. 拖动屏幕移动（键盘 WASD / 方向键），英雄自动瞄准开火，你只负责走位和挡子弹。
2. 中心水晶基础 150 点耐久，怪物撞上来就掉血；低于 32% 时全屏红边呼吸警示。
3. 清空一波 → 金币奖励 + 水晶自愈 +8 → 波间商店。
4. 每升一级弹出 3 张卡（12 张战斗卡 + 3 张补给卡，每次最多 1 张补给卡），同名卡可叠加。
5. **进化卡**：满足前置（例：烈焰弹头 2 级 + 三叉火力 2 级）时刷出金色「进化」卡 —— 凤凰弹幕 / 霜刺风暴 / 连锁爆裂，一局各 1 次。
6. **永久成长**：每局按新守住的波数结算晶体（3 晶体 / 波），在「永久强化」里买 4 条永久属性，跨局保留。
7. **每 5 波首领**：烈焰（召唤 + 三连弹幕）→ 疾风（突进 + 五连弹幕）→ 铁壁（重甲 + 召唤护盾兵）轮换，弹幕可被英雄肉身拦截。
8. 无限波次，最高纪录 / 晶体 / 永久强化等级存本地。

## 内容

- 9 种敌人：史莱姆、冲锋兵、重甲、分裂体（死后分裂）、远程喷吐、分裂子体、**护盾兵**（正面装甲减伤 55%）、**自爆虫**（贴水晶自爆，一击 18）、首领。
- **精英怪**：第 6 波起 14% 概率出现，血量 ×2.2、掉落 ×3，金色虚线环。
- 12 张升级卡：烈焰弹头、超频扳机、三叉火力、穿甲弹芯、致命一击、爆裂弹芯、霜冻弹、伴飞无人机、长管增压、拾取磁场、吸能护盾、水晶装甲。
- 3 张补给卡 + 3 张进化卡。
- 商店 4 条成长线：攻击 +10%/级、射速 +8%/级、暴击 +3%/级、修复 30 点。
- 永久强化 4 条：伤害 +6%/级、射速 +4%/级、水晶耐久 +12/级、开局金币 +12/级（各 5 级）。
- 手感层：自动瞄准、扇形弹道、穿透、暴击、爆炸、冰冻、僚机、吸血护盾、连击、屏震、顿帧、伤害飘字、经验吸附、装甲击穿反馈、残血警示、首局引导。

## 数值

- 水晶 150（+12/级永久强化），波间自愈 +8，复活回到 60%
- 敌血 `19 × 1.10^(w-1) + 6 × (w-1)`；每波数量 `min(4 + 1.8w, 34)`，首领波 ×0.6 再插入首领
- 首领血量 10 倍单位血量、接触伤害 22、弹幕 30%；铁壁形态额外 35% 装甲
- 晶体结算 `max(2, 3 × 本局新守住的波数)`，复活后只结算新增波数
- 实测（无头 Chromium 定步长对局）：纯走位 bot 约 8–9 波 / 100 秒；带永久强化可到 12 波以上，单局 3–6 分钟

## 目录
