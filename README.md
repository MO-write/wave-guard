# 怪潮守卫 · Wave Guard

> 拖动走位，自动开火，守住中心水晶，看你能扛过多少波怪潮。

单文件、纯 Canvas、零外部素材的竖屏「波次守城」小游戏。双击 `index.html` 即玩，不需要联网、构建或服务器。

- 在线试玩：https://4mdqufrebrmf9.doubao.link/app/app_17jpzbcgn8f
- 引擎：原生 Canvas 2D + WebAudio，设计分辨率 750×1333（9:16）
- 包体：单文件约 91 KB，无任何外部图片 / 音频 / 字体

## 玩法

1. 拖动屏幕移动（键盘 WASD / 方向键），英雄自动瞄准开火，你只负责走位和挡子弹。
2. 中心水晶 150 点耐久，怪物撞上来就掉血，血量越低颜色越危险（青 → 金 → 红）。
3. 清空一波 → 金币奖励 + 水晶自愈 +8 → 波间商店。
4. 每升一级弹出 3 张卡（12 张战斗卡 + 3 张补给卡），同名卡可叠加。
5. 每 5 波首领：半血召唤小怪 + 三连弹幕，弹幕可被英雄肉身拦截。
6. 无限波次，最高纪录存本地。

## 内容

- 7 种敌人：史莱姆、冲锋兵、重甲、分裂体、远程喷吐、分裂子体、首领。
- 12 张升级卡：烈焰弹头、超频扳机、三叉火力、穿甲弹芯、致命一击、爆裂弹芯、霜冻弹、伴飞无人机、长管增压、拾取磁场、吸能护盾、水晶装甲。
- 3 张补给卡：水晶修复、护盾充能、金币补给。
- 商店 4 条成长线：攻击 +10%/级、射速 +8%/级、暴击 +3%/级、修复 30 点。
- 手感层：自动瞄准、扇形弹道、穿透、暴击、爆炸、冰冻、僚机、吸血护盾、连击、屏震、顿帧、伤害飘字、经验吸附。

## 广告点位（IAA，全部可选）

| 点位 | 触发 | 频次 | 奖励 |
| --- | --- | --- | --- |
| 复活再战 | 水晶破碎 | 每局 1 次 | 恢复 60% 耐久，当前波重打 |
| 免费刷新 | 升级选卡 | 每次升级 1 次 | 重抽 3 张卡 |
| 金币翻倍 | 波间商店 | 每波 1 次 | 本波金币 ×2 |

不看广告也能正常通关；无强制插屏。上线时替换为穿山甲激励视频 `tt.createRewardedVideoAd`。

## 数值

- 水晶 150，波间自愈 +8
- 敌血 `19 × 1.10^(w-1) + 6 × (w-1)`；每波数量 `min(4 + 1.8w, 32)`，首领波 ×0.6 再插入首领
- 首领血量 10 倍单位血量、接触伤害 22、弹幕 30%
- 实测：随机走位约 8 波 / 100 秒；正常选卡 13 波 / 170 秒仍在继续

## 目录

```
index.html          # 构建产物，直接可玩
build.sh / build.ps1 # macOS·Linux / Windows 构建脚本
src/                # 分片源码（shell_head + 00~05 + shell_tail）
```

改完分片后执行 `bash build.sh` 或 `powershell -File build.ps1` 重新生成 `index.html`。

## 素材
