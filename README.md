# 怪潮守卫 · Wave Guard

> 拖动走位，自动开火，守住中心水晶，看你能扛过多少波怪潮。

单文件、纯 Canvas、零外部依赖的竖屏怪潮防守小游戏。双击 `index.html` 即可开玩，无需联网、无需构建、无需服务器。

**v3 新增（观感与内容重做）**：主视觉标题页（AI 生成场景图 + 活体怪潮展示）、10 项成就、3 个挑战副本（狂暴 / 贫瘠 / 铁壁，晶体 +50%）、合成和弦 BGM、首领入场故障警报、敌人重绘（爬行腿足 / 甲刺 / 发光杏眼 / 地面反光）、光束拖尾子弹、水晶双面切割与环绕碎晶、战场星云漂移。

**v2 新增**：永久成长（晶体 + 4 条永久强化）、8 张卡触发的进化卡、护盾兵 / 自爆虫、金色精英怪、3 种首领形态、残血警示、首局引导。

## 立即开玩

- 电脑：双击 `index.html`，Chrome / Edge / Safari 均可。
- 手机：把 `index.html` 发到手机用浏览器打开，或部署到任意静态托管（GitHub Pages 可直接用仓库根目录的 `index.html`）。
- 竖屏 9:16 设计（750×1333），任意屏幕等比缩放，桌面端自动居中留边。

## 玩法

1. **拖动移动**：手指按住屏幕拖动（键盘 WASD / 方向键），英雄自动瞄准并开火，你只负责走位和挡子弹。
2. **守住水晶**：中心水晶基础 150 点耐久，怪物撞上来就掉血；血量低于 32% 时屏幕边缘红边呼吸警示。
3. **清空一波 → 结算**：金币奖励 + 水晶自愈 +8 → 进入波间商店。
4. **升级三选一**：每升一级弹出 3 张卡（12 张战斗卡 + 3 张补给卡，每次最多 1 张补给卡），同一张卡可叠加等级。
5. **进化卡**：满足前置（如「烈焰弹头 2 级 + 三叉火力 2 级」）时，升级界面会刷出金色「进化」卡——凤凰弹幕 / 霜刺风暴 / 连锁爆裂，一局各限 1 次。
6. **永久成长**：每局按新守住的波数结算晶体（3 晶体/波），在「永久强化」里买 4 条永久属性（攻击 / 射速 / 水晶耐久 / 开局金币），跨局保留。
7. **每 5 波首领**：烈焰（召唤 + 三连弹幕）→ 疾风（突进 + 五连弹幕）→ 铁壁（重甲 + 召唤护盾兵），三种形态轮换；弹幕可被英雄肉身拦截。
8. **挑战副本**：标题页三个挑战词条——狂暴（敌人 +30% 速、-15% 血、金币 +40%）、贫瘠（金币 -45%、经验 +30%）、铁壁（敌人 +25% 血、+20% 装甲）。挑战局晶体 +50%，各自记录最高波数。
9. **成就**：10 项跨局成就（守 10/20 波、单局 120 杀、连击 40、击破 3 首领、不用复活守 12 波、拿到进化卡、累计 100 晶体、永久强化 5 级、挑战 5 波），首次达成立刻结算并给晶体。
10. **无限波次**：怪物数量与血量随波次上涨，最高纪录存本地。

### 内容量

- 9 种敌人：史莱姆、冲锋兵、重甲、分裂体（死后分裂）、远程喷吐、分裂子体、护盾兵（正面装甲减伤 55%）、自爆虫（贴水晶自爆，一击 18）、首领。
- 精英怪：第 6 波起 14% 概率出现，血量 ×2.2、掉落 ×3、金色虚线环。
- 12 张升级卡 + 3 张补给卡 + 3 张进化卡 + 3 个挑战词条 + 10 项成就。
- 4 条商店成长线：攻击 +10%/级、射速 +8%/级、暴击 +3%/级、水晶修复 30 点。
- 4 条永久强化：伤害 +6%/级、射速 +4%/级、水晶耐久 +12/级、开局金币 +12/级（各 5 级）。
- 手感层：自动瞄准、扇形多弹道、穿透、暴击、爆炸、冰冻减速、无人机僚机、吸血护盾、连击金币加成、屏震、顿帧、受击闪白、伤害飘字、经验碎片吸附、装甲击穿反馈。

## 广告点位（IAA，全部可选）

| 点位 | 触发时机 | 频次 | 奖励 |
| --- | --- | --- | --- |
| 复活再战 | 水晶破碎后 | 每局 1 次 | 恢复 60% 耐久，从当前波重打 |
| 免费刷新 | 升级选卡界面 | 每次升级 1 次 | 重抽 3 张卡 |
| 金币翻倍 | 波间商店 | 每波 1 次 | 本波金币 ×2 |

设计口径：**不看广告也能正常通关**，广告只卖“加速”，不卖“通过”；无强制插屏、无 banner 遮挡。当前为 3.2 秒模拟素材，真实上线时替换为穿山甲激励视频（`tt.createRewardedVideoAd`），`onClose` 判断 `isEnded` 后再发奖。

## 数值与难度

- 水晶耐久 150（+12/级永久强化），波间自愈 +8，复活回到 60%。
- 敌人血量 `16 × 1.10^(w-1) + 5 × (w-1)`；每波数量 `min(4 + 1.9w, 44)`，同侧成组（每组 7 只）涌出形成潮水；首领波数量 ×0.6 后再插入首领。
- 首领血量 10 倍单位血量、接触伤害 22、弹幕单发为接触伤害的 30%；铁壁形态额外 35% 装甲。
- 英雄基础：伤害 16、射速 0.34s、射程 470、护盾 60（破盾眩晕 1.25s）。
- 晶体结算：`max(2, 3 × 本局新守住的波数)`，挑战局 ×1.5，复活后只结算新增波数、不重复给。
- 实测（无头 Chromium 自动对局，60fps 定步长）：纯走位 bot 约守 8 波 / 70–90 秒；神模式跑到 15 波无报错；带永久强化后真人体感可到 12 波以上，单局 3–6 分钟。

## 已实测

- 360×640、390×844、430×932、768×1024、1280×800 五种视口，HUD / 升级卡 / 商店 / 结算均无溢出。
- 390×844 @2x，同屏 23–26 只怪时约 56–57 fps。
- v2 回归：13 波长局（含 3 次首领、精英怪、护盾兵、自爆虫）无 JS 报错；永久强化购买后 `coreMax 174 / 开局金币 24` 正确生效；标题→永久强化→关闭、结算→永久强化→关闭、升级选卡→继续、重开 全部状态流转正确。
- v3 回归：挑战模式启动 / 词条乘算（`spd 1.3 / hp 0.85 / coin 1.4`）/ 结算标题显示 / 重开保持挑战，全部正确；成就结算与晶体发放无重复；标题→永久强化→返回、升级三选一、未结束的进化卡判定、结算→重开 全部通过；非神模式 bot 守到 8 波、神模式 15 波全程零 `onerror`。
- 长局回归：连续 13 波、含 3 次首领战无异常；复活、刷新、翻倍三个广告点位均验证生效且只发一次奖励。
- 切后台自动暂停；静音、最高纪录、晶体、永久强化等级全部持久化。

## 移植抖音小游戏（ttmg）

1. `index.html` 拆成 `game.js` + `game.json` + `project.config.json`，用抖音开发者工具创建“小游戏”项目。
2. Canvas 换成 `tt.createCanvas()`；触摸事件换 `tt.onTouchStart / tt.onTouchMove / tt.onTouchEnd`。
3. 激励视频：`tt.createRewardedVideoAd({ adUnitId })`，`show()` 失败时先 `load()` 再 `show()`；`onClose(res => res.isEnded && grant())`。
4. 侧边栏复访：`tt.navigateToScene({ scene: 'sidebar' })`，配合每日首次进入奖励。
5. 分享：`tt.shareAppMessage({ title, imageUrl })`，用战斗截图做分享图。
6. 包体：当前单文件约 309 KB（含内联标题主视觉）、无外部依赖，远低于 4 MB 首包限制。

## 素材与版权

游戏内所有敌人、水晶、英雄、子弹、特效与音效都由 Canvas / WebAudio 程序化实时绘制与合成；标题页主视觉为 AI 生成的原创场景图（Seedream），已压缩后以 base64 内联进单文件，**不含任何第三方图片、音频、字体或模板素材**，可商用。

    ├── 00_core.js      # 常量、工具、WebAudio 音效与 BGM、输入摇杆
